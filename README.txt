重要
PWAとしてインストールするには、index.html を直接開くのではなく、
HTTPSで配信されているWebサイトとして開く必要があります。
GitHub Pages、Cloudflare Pages、Netlify等の無料ホスティングに
このフォルダ一式を置けば利用できます。

Android Chromeで公開URLを開くと、
「インストール」ボタンまたはChromeメニューの
「アプリをインストール」「ホーム画面に追加」からインストールできます。
